# Feasibility Study

**Digital Certificate Verification System**

Faculty of Computers and Information, Menoufia University | System Analysis

---

## 1. Feasibility Assessment

| Type | Proposed Solution / Benefits | Feasibility Result |
|---|---|---|
| **Technical** | - Web-based system with a database (MySQL)<br>- Unique verification code and QR code per certificate<br>- Cloud hosting with automatic backups. | ✓ **Technically feasible** |
| **Operational** | - Instant self-service verification for employers.<br>- Admin dashboard to add, update and revoke certificates.<br>- Reduced staff workload and simple interface with short staff training. | ✓ **Operationally feasible** |
| **Economic** | - Saves staff time,paper and printing.<br>- Reduces forgery-related risk.<br>- Lower admin costs and long-term efficiency gains. | ✓ **Cost-effective** |
| **Legal** | - Role-based access control, encrypted data, minimal data shown on the public page, audit log.<br>→ comply with data-protection rules (e.g., Egypt Personal Data Protection Law No. 151 of 2020) and university policies. | ✓ **Legally feasible** |
| **Time** | - Timeline 3–6 months<br>(requirements → design → development → testing → deployment). | ✓ **Achievable timeline** |

## 2. Cost–Benefit Analysis

*All amounts are estimates in US dollars. Total costs exclude the existing manual-process cost (Administration), which is counted as a yearly saving.*

| Category | Description | Estimated Cost – Low ($) | Estimated Cost – High ($) | Benefits | Estimated Value (per year) |
|---|---|--:|--:|---|--:|
| **Software** | In-house development (web app, verification page, admin dashboard) or purchase of a license | $1,500 | $4,000 | Automated verification reduces errors and manual handling | $2,500 |
| **Hardware & Hosting** | Cloud server/hosting, domain, SSL, backup storage | $150 | $600 | Instant online verification; far fewer verification requests handled by staff | $600 |
| **Training** | Training sessions for Student Affairs staff | $300 | $800 | Smooth transition and efficient use of the system | $800 |
| **Maintenance** | Annual updates, bug fixes, security patches, hosting renewal | $700 | $1,200 | Ensures system reliability and security; avoids downtime and fraud cases | $1,500 |
| **Legacy Data Digitization** | Entering previous graduates’ certificate records into the system | $600 | $1,500 | Searchable records; faster retrieval of old certificates | $700 |
| **Administration** | Current manual process (paper letters, printing, courier, staff time) – existing yearly cost | – | – | Eliminated with the system → paperless verification | $1,200 |
| **User Experience** | Employers and graduates wait days for manual verification | – | – | Verification in seconds; improved satisfaction and trust | Intangible but high value |
| **Total** | | **$3,250** | **$8,100** | | **$7,300** |

### Summary
