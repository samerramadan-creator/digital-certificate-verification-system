# 🎓 Digital Certificate Verification System

> System Analysis — Faculty of Computers and Information, Menoufia University (2026–2027)

---

## 📌 Project Name

> Digital Certificate Verification System

---

## ⚠️ Current Problems

1. Slow manual verification (paper letters and phone calls)
2. Paper certificates are easy to forge
3. Heavy workload on Student Affairs staff
4. No central digital record of certificates
5. Employers cannot verify certificates by themselves

---

## 📝 Description of Project

> The system replaces the manual certificate verification process with a secure, centralized digital platform. Each graduate's certificate is stored in a database with a unique verification code and QR code, so any employer or institution can confirm its authenticity within seconds through a public verification page. Student Affairs staff manage certificates (add, update, revoke) from an admin dashboard, while an audit log records every verification and administrative action. The result is faster verification, fewer forgery risks, and less manual work.
